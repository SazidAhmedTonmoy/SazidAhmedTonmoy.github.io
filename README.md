# SazidAhmedTonmoy.github.io 🌐

The source repository for my personal engineering portfolio website, hosted via **GitHub Pages** at **[sazidahmedtonmoy.github.io](https://sazidahmedtonmoy.github.io)**.

This site showcases my work as an **IoT & Edge AI Software Engineer**, featuring my professional deployments at **ATPL Dhaka** and **BDCOM**, alongside my undergraduate computer vision and machine learning research at **North South University**.

---

## ✨ Key Features

* **Interactive Project Filtering:** Dynamically filter engineering projects across *ATPL & Industry*, *Edge AI & IoT*, and *Embedded C (BDCOM)*.
* **Animated Role Typewriter:** Interactive header highlighting core specialties in Edge AI, Python automation, computer vision, and embedded Linux.
* **Glassmorphism Dark UI:** Built with a responsive Tailwind CSS layout, custom SVG/PNG branding (`logo.png`), and clean visual hierarchy.
* **Zero-Build Static Architecture:** Pure HTML, Tailwind CDN, and vanilla JavaScript for instant deployment on GitHub Pages.
